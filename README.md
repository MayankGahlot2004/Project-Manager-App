# Project-Manager-App
This iOS application is a streamlined Project and Task Management System designed using UIKit. 
It begins with a Login and Registration interface, ensuring secure access. Users are prompted with alerts if any fields are left incomplete, enforcing proper input validation.
Upon successful login, users are navigated to the Admin Dashboard, where they can add new projects by entering the project name, description, and priority level (indicating its importance).
Each added project is displayed on the dashboard with a delete option for completed projects.
Clicking on a project name takes the user to a dedicated Task page, where they can add tasks specifically related to that project. 
This structured flow helps users manage multiple projects and their associated tasks with clarity and ease.
